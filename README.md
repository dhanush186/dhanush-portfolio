## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or pnpm

### Installation

1. Clone the repository:

    ```bash
    git clone https://github.com/dhanush186/portfolio.git
    ```

2. Navigate to the project directory:

    ```bash
    cd dhanush-portfolio
    ```

3. Install dependencies:

    ```bash
    npm install
    ```

4. Run locally:

    ```bash
    npm run dev
    ```

5. Build for production:

    ```bash
    npm run build
    ```
